GraphUnslopify

An MCP server and HTTP API that will translate JSON plot specifications into matplotlib code.

MVP. The transport and tool registration work. The translation does not exist yet. Sending JSON returns json successfully passed and a description of what arrived.

Endpoints

PathMethodPurpose
/api/mcpGET, POST, DELETEMCP Streamable HTTP
/api/convertPOSTPlain HTTP twin of the tool
/api/healthGETLiveness

Connect an MCP client

claude mcp add --transport http graph-unslopify \
  https://<this-host>/api/mcp

Or just curl it

curl -X POST https://<this-host>/api/convert \
  -H 'content-type: application/json' \
  -d '{"kind":"line","x":[1,2,3],"y":[4,5,6]}'
